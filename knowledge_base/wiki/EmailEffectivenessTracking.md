==How effective is that email?==
===Broadcast Email===
Measure:
*Date Sent
*Subject Line
*Email Type (content/promotional/...)
*Campaign
*Email # in sequence
*Total Number sent
*Number delivered
*Number of Opens
*Number of Clicks
*Unsubscribes
*Complaints
*Delivery Percentage (Delivered / Sent)
*Open percentage (Open / Delivered )
*Click Rate  (Click / Delivered)
*Click / Open
*Complaint Percent ((Unsub + complaint) / Open)
===Automated Email===
Measure:
*Date Range (Start)
*Date Range (End)
*Subject Line
*Campaign
*Email # in sequence
*Total Number sent
*Number delivered
*Number of Opens
*Number of Clicks
*Unsubscribes
*Complaints
*Delivery Percentage (Delivered / Sent)
*Open percentage (Open / Delivered )
*Click Rate  (Click / Delivered)
*Click / Open
*Complaint Percent ((Unsub + complaint) / Open)
