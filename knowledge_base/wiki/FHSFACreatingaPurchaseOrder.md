==Create a Purchase Order==
 The normal order of operations:
 #Place purchase order
 #Supplier fulfills (ships) the order
 #The supplier invoices the order
 #You receive the order
 #You enter the Supplier Invoice
 #You pay the Supplier Invoice
 You can go straight to Direct Purchase Invoice which generates the PO, Reception and Invoice in one step.
#Purchase Order Tab
#Click Purchase Order Entry
#Select appropriate data
##Supplier
##Date
##Receive Into
#Add items
##type in code or select from dropdown
##add number of items
##check price
##Click Add Item
#Add a line entry for shipping (SHIP) if there will be a shipping charge.  Estimate if the cost is unknown (start around $20)
#Add notes if appropriate (Memo box)
#Click Place Order
#Click Print This Order
#If the supplier takes POs by email, you can also click Email this order
#If items have arrived at the time of creating, you can also click [[FHS FA Receive Shipment‎‎|Receive Items]] on this Purchase Order

 Note in this image we are editing an existing PO, so we have an UPDATE button rather than process.
