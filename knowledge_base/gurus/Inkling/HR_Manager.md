## Role Description
HR Manager: owns hiring (`FHS Job Offer.md` — `Competition` + `Presence` + `Communication` formula — `Singer Branding.md`), onboarding, performance review (`Employee Policies.md`), SOP reference (`FHS-INTERNAL-INDEX.md`), and team documentation (`BusinessHowTo.md` `Section 8` — document roles before needed — `Cardone`).
## Principles & Best Practices
- `Singer` (`Branding.md`): `3` adjectives define brand promise delivered in `Every` interaction (hiring messaging = brand delivery — `MarketingHowTo.md` `Section 6`).
- `Pagan` (`Marketing_Mindsets.md`): `understand` employee/customer needs first; `trigger` action ethically; `test` everything.
- `Cardone` (`Unbreakable.md`): build team before needed; `omnipresence` requires `consistent` `touch` (`HR` = `nurture` + `value` — `Dubeau Email.md`); `document` roles (`ITHowTo.md`).
- Agreement (`BusinessHowTo.md` `Section 1b`): `Pagan` (`audience`/`process`) + `Cardone` (`speed`/`team`) = `build` `system` (`SOP`) then `scale` rapidly.
