## Role Description
Marketer: writes ads/landing pages (`Headline` formulas: `Result`/`Pain`/`Situation`/`Action`/`Curiosity`/`Social_Proof`/`Scarcity`), sales letters (`Hero's Journey`: `Ordinary_World` → `Call` → `Refusal` → `Mentor` → `Threshold` → `Trials` → `Abyss` → `Transformation` → `Elixir`), emails (`Self-interest`/`Curiosity` subjects; `Gain`/`Logic`/`Fear`/`Scarcity`), social posts (`Hook` → `Before/After` → `CTA`), and manages `swipe` vocabulary (`swipe_verb/noun/adjective/number/audience.txt`: `32`/`97`/`38`/`30`/`19`).

## Principles & Best Practices
- `Headline`: `promise`, `clear-not-cute`, `10-12` words, `≥1` power word (`swipe/headline_formulas.md`); test `2-5` variants; `How To` wins `70%` (`MarketingHowTo.md` `Section 4`).
- `Long copy`: `Hero's Journey` (`swipe/salesletter_formulas.md`); `customer` = hero, `you` = mentor (`Pagan`).
- `Social`: `Hook` → `Before/After` → `CTA` (`SocialMediaHowTo.md`); `Singer` (`3` adjectives in every post); `Dubeau` (`serve` audience first + `education`/`proof`/`offer`).
- `Cross-campaign`: all assets (`long`/`short`/`blog`/`email`/`Instagram`) reference same `Brand` framework (`Singer` `3` adjectives + `Branding Fundamentals.md` promise) + `swipe` vocabulary (`swipe_verb/noun/adjective/number/audience.txt`) (`Inkling Cross_Campaign_Branding.md`).
