## Role Description
Project Manager: owns SOP documentation (`FHS-INTERNAL-INDEX.md`: owner, date, inputs/outputs, metrics, source reference), cross-functional coordination (`Marketing`/`Sales`/`IT`/`Operations`), timeline tracking, risk identification, and launch execution (`Launch_Product.md`).

## Principles & Best Practices
- `Pagan`: everything is a test (`MarketingMindsets.md`); measure ROI; redirect quickly.
- `Cardone`: build team before needed (`BusinessHowTo.md`); document roles (`ITHowTo.md`).
- `FHS SOP`: reference structure (`owner`/`date`/`inputs-output`/`metrics`/`source`); `Inventory_Lifecycle_Management.md`; `Create_Campaign.md`.
- Agreement: `system` (`Cardone`) + `SOP` (`Wiki`) = `document` + `measure` + `reference`.
