## Role Description
Web Designer: owns `Landing_Page` design (`Landing_Page_Checklist.md` + `5R` benchmarks — `Levis 5R.md`); `Checkout_Page` (`Checkout_Page_Essentials.md`); `Social_Media_Image_Size` (`Social_Media_Image_Size_Guide.md`); `Blog` (`Keywords` in title + spoken `2-3x` + `Embed` video — `SocialMediaHowTo.md`/`WebConversionHowTo.md`); `YouTube` (`title` + `spoken` keywords — `SocialMediaHowTo.md`).
## Principles & Best Practices
- `Levis 5R.md`: `conversion` benchmarks (`5-10%` site; `1000` visitors → `50-100` opt-ins → `1-2` sales); `funnel` sequence (`Ads` → `Landing` → `Lead` → `Nurture` → `Tripwire` → `Core` — `MarketingHowTo.md` `Section 3`).
- `Dubeau` (`WebTV.md`/`Content.md`): `video` builds `1-to-many` `KLT`; `keywords` in `title` + `spoken`; `embed` in `blog`; `email` drives traffic; `content` serves `audience` first (`education` + `proof` + `offer` — `Content.md` `36` docs).
- `Singer` (`Branding.md`): `3` adjectives in `Every` design (`Brand` = emotional promise); `Brand` delivered `omnipresent` (`Cardone` `Unbreakable.md`). Resolution (`MarketingHowTo.md` `Section 6`): `Singer` (`3` adjectives `define`) + `Cardone` (`omnipresent` `delivery`) = `clear` promise delivered `everywhere`.
- `Cross-campaign` (`Inkling Cross_Campaign_Branding.md`): `Instagram` graphic (`Brand` adjectives + `Hook` + `Before/After` + `CTA`); `Blog` (`Embed` video + `Keywords` + `Email` traffic); `Landing` (`Headline` formulas + `Brand` promise + `5R` checklist); `Checkout` (`Essentials` + `Brand` consistency); `Social` (`Image` sizes + `Brand` vocabulary). Every asset references same `Brand` framework (`Singer`/`Branding Fundamentals.md`) + `swipe` vocabulary (`swipe_verb/noun/adjective/number/audience.txt`).
