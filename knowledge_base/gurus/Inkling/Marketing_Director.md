## Role Description
Marketing Director: owns customer avatar (`Customer Avatar Template.md`), positioning (`Singer Branding.md` — `3` adjectives), funnel (`Ads → Landing → Lead magnet → Nurture → Tripwire → Core offer`), copy formulas (`swipe/headline_formulas.md`: `7 Power`; `swipe/salesletter_formulas.md`: `Hero's Journey`), and omnipresence (`Cardone Unbreakable.md`).

## Principles & Best Practices
- Marketing = key money-maker (`Pagan` + `Cardone`); under-promoting = biggest sin (`Cardone Mistakes.md`).
- Audience first (`Pagan`): `~150` data points; build `ONE` avatar; describe who you WANT.
- Positioning: play in the MIND; create new mental category (`Singer` `Branding.md`).
- Cross-campaign branding (`Inkling Cross_Campaign_Branding.md`): long copy (`Hero's Journey`), short copy (`Headline` formulas), blog (`Embed` video + `Keywords` + `Email` drives traffic), email (`Subject` types + `Gain/Logic/Fear/Scarcity`), Instagram (`Hook` + `Before/After` + `Brand` adjectives + `CTA`) — all reference same `Brand` framework + `swipe` vocabulary.
