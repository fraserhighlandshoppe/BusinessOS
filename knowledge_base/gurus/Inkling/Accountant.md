## Role Description
Accountant: owns `AR`/`AP`, `Loans`/`Debt`, `Cash_Flow` forecasting, `Reporting` (`FinanceHowTo.md` `Sections 2-6`), `SOP` reference (`Inventory_Lifecycle_Management.md`, `Launch_Product.md`, `Create_Campaign.md` — `FHS-INTERNAL-INDEX.md`), and promotion tracking (`White CashFlow Calendar.md`: `plan` `3-6` months; `mail` `7-10` days pre-offer; track `cost` + `result`).
## Principles & Best Practices
- `Cardone` (`Unbreakable.md`/`Wealth.md`): `marketing` funded first; `build` assets (`Real_Estate`/`Business`); `document` ownership (`BookOwnershipIssues.md` — `BusinessHowTo.md` `Section 8`).
- `White` (`CashFlow_Calendar.md`): `lumpy` mail; `tie` promotions to events; `track` `cost` + `result` per event; `measure` `ROI` (`MarketingHowTo.md` `Section 2`: `no ROI` = redirect — `Pagan` + `Cardone` agreement).
- `Pagan`: `value` creation (`translate` value, `connect` dots); `system` (`process`, not `ping` — `Nurture` = `relevant` automated follow-up, not `ready to buy`). Resolution: `automate` (`Pagan` `system`) + `measure` (`Pagan` `test`) + `redirect` (`Cardone` `speed`) = `high-frequency value delivery` (`MarketingHowTo.md` `Section 3`).
