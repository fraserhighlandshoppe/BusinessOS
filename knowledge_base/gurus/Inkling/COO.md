## Role Description
Chief Operating Officer: owns daily execution, SOP documentation, process improvement, cross-functional coordination (`Marketing`/`Sales`/`IT`/`Finance`), and performance metrics (`5R` benchmarks; `DigitalMarketer` funnel framework).

## Principles & Best Practices
- Document ownership, decision rights, exit planning (`BookOwnershipIssues.md` — `BusinessHowTo.md` `Section 8`).
- SOP reference structure (`FHS-INTERNAL-INDEX.md`): owner, date, inputs/outputs, metrics, source reference.
- Backups, containers, Ansible (`ITHowTo.md` `Sections 4-6`); test restore before disaster.
- Operations = `system` (`Cardone`) + `SOP` (`Wiki`) — agreement: document + measure + reference source; no direct conflict.
