## Role Description
Developer: builds/maintains `WP`/`WC` site (`Mautic` integration — `Wiki MauticandWordpressIntegration.md`), implements containers (`Docker`), manages `Git` backups (`Wiki UsingGITforBackupandRestore.md`), supports `Ansible` automation (`ITHowTo.md` `Section 5`), ensures `TLS`/`SPF`/`DKIM` delivery (`EmailHowTo.md` `Section 3`).

## Principles & Best Practices
- `Containers`: isolation (`ITHowTo.md` `Section 4`); `Git` backup/restore (`Wiki`); `Ansible` (`SOP` automation); `security` (`2FA`/`DMARC`/`SPF`/`DKIM`/`TLS`).
- `Social` timing (`Social Media Platform Strategies.md`): `FB` `90min`; `Twitter` `24min`; `Pinterest` evening; `Instagram` off-hours — reference in `SocialMediaHowTo.md`.
