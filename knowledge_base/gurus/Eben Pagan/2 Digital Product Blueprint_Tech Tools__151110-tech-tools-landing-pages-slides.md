Introduction to Landing Pages

What is a landing page?
• For our purposes, it’s a web page that receives

traffic from an advertising or marketing campaign
for the purpose of generating an opt-in lead.
• Typically separate from the main site and

optimized for a single call to action.

What is a landing page?
• Various types of landing page — clickthrough, retargeting,

native ads, and lead gen.
• This training focuses on:
• Optin pages for freeline content, leading to indoctrination

or education series, sales funnels, even product launches.
• Registration pages for virtual events (e.g. webinars)
• Segmented options to tailor custom followup campaigns

What is a landing page?
• Landing pages/sequences are typically not a part of the main

site/blog.
• There are typically many of them, each with a message

targeted to one of potentially many avatar needs/wants and
characteristics; each with a potentially unique message
• May be a standalone domain, a subdomain of the main site or

simply a link to a hosted service (e.g. LeadPages) depending on how much branding/visibility is required

Integrations

Integrations - Content Delivery
• Downloads
• Upload to web (Amazon S3, Dropbox, Google

Drive, Blog Content Folder…etc)
• Put link to the download file on the “thank you”

page
• (Built in to lead pages)

Integrations - Content Delivery
• In a membership area or standalone web page
• On thank you page, have a link to
• The standalone web page (with any login details)
• The registration page for the member area
• Simple hybrid: a password protected page/post

on your blog

Integrations - Autoresponder
• If using a SAAS or plugin that supports integration

with your autoresponder, use that.
• Otherwise, create a form in your autoresponder and

copy/paste the code for that form into your optin page
• When creating form in autoresponder, be sure to use

the optin-confirmation and thank-you page URLs from
the appropriate landing page sequence.
