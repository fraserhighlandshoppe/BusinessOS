Overview

Overview
• Membership sites generically mean - a site to which content

is restricted to authorized members
• Can be
• One time (aka digital product)
• Fixed term
• Recurring (content / payments)
• Either paid or free

Overview
• For our purposes, we’re focusing on delivering a digital

product / training course that is broken down into modules
then lessons.
• Could be as few as a single module with multiples lessons;

or multiple modules with multiple lessons
• Let’s focus on immediate (not dripped) access
• This represents the 80%+ of use cases that’ll jumpstart you

Membership Software Controls:
• User management
• Content Access Management
• Optionally: Time-released (aka “dripped”) content
• (Recurring) Payment Management - or integration

with commerce system

Membership Site Elements
• Content format (e.g. digital product, course, etc)
• Content pages and navigation
• Access protection
• Payment / Subscription
• List subscription / followup

Membership Site Elements

WP Membership Sites
• WP defines the content and navigation on pages and

posts.
• Relies on Membership Software to register, maintain

and delete users; and define what users have access
to what content
• Payments are handled by either the membership

software or a third party cart the software

WP Membership Sites
• There are countless number of WP membership site

plugins now
• That, and the SAAS membership options abound too
• We can help identify some of the other options but to

keep things simple, we’ll demonstrate using WP
Wishlist plugin

WP Membership Sites
• In the end, if you learn the principles and objectives

of what we’re doing — it’ll be relatively easy to use
any other membership site plugin (the core features
and integrations are pretty similar).
• Easy, affordable, flexible, robust and well supported

— a good way to get started with a wordpress
based solution.

• It’s about defining and setting up the infrastructure to

upload, create, sell and control access to the content in a
membership site
• Watch for that, don’t sweat the look’n’feel - you will have

total control of it on your site.
