Nuts & Bolts:

How to Put Static Web Pages
Online
Key Points:
1. Blog pages are great for getting free search engine traffic. They are not so good at
converting visitors to subscribers or at selling people stuff. For that, generally
speaking, static pages are better. They have less to distract visitors - so it's easier to
direct their attention to taking the action you want them to.
2. You don't HAVE to have a blog. And you don't HAVE to have static pages. You can
have one or the other, or both... the choice is yours.
3. You can have both blog pages and static pages on a single website. Generally, your
blog will be at www.yoursite.com/blog.
4. To make changes to the blog portion of your site, just type in "/wp-admin" after the
location of your blog, for example, www.yoursite.com/blog/wp-admin. You don't
need any special software.
5. To make changes to static web pages, you need two pieces of software - one to create
and edit the pages (called an HTML editor… think of this like Microsoft Word)...and
one to send these pages to the Internet (called an FTP client.) Big names, simple
programs... don't get intimated.
6. If you are technically inclined, Dreamweaver ($400) is a good program that has both
an HTML editor and an FTP program.
7. If you're not technically inclined, free options include Filezilla for FTP and Kompozer
for HTML. Both of these programs work for PC's and Mac's. Coffee Cup is another,
but it's $50. Just Google them to find them.
8. When you set up your FTP program, enter your hosting user name, password, and
server or host name. Get this information from your hosting company, for example,
GoDaddy. If you get stuck and your FTP cannot "connect" to your server, call up
GoDaddy and see if they can help. If they can't, pay someone on Elance $20 to sync
up your FTP program with your server.
9. Use your HTML editor like you would use Word. Choose font, alignment, etc.
10.Use the "code view" in your HTML editor to view the code. This is where you can
insert code from PayPal to put up a “buy now” button... code from Aweber to install
an opt-in box... code from YouTube to post a video...etc.
11.Drag your HTML files into the place you want them on your website using your FTP
program. That's one way to put them online.

Action Steps:
1. Download and install an FTP client and HTML editor.
2. Connect your FTP program to your hosting server.
3. Create a practice page using your HTML editor.
4. Use your FTP program to put that page online.
5. Type in the address and verify the page is up... there you go!
