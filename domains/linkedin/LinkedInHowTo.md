LinkedIn = professional network + authority builder (`SocialMediaHowTo.md`). Company page + personal profiles (shareholder/team) must align.

---

## 2. Profile Setup (Personal + Team)

Based on `7 Tips...md` (`domains/linkedin/`):
1. Professional headshot; brand colors; 3-adjective brand (`Singer Branding.md`).
2. Headline: not just title — include value prop (`MarketingHowTo.md` Section 6; `swipe/headline_formulas.md`).
3. Summary: before/after story (`swipe/salesletter_formulas.md` skeleton); include owner story (`FHSKevinOwnerBio.md` for shareholder profiles).
4. Featured content: video (`Dubeau Web TV.md`); landing page links (`Landing Page Checklist.md`).
5. Skills/endorsements: match customer avatar skills (`Customer Avatar Guide.md`).

---
**Source: `7 Tips...md` + `Branding Fundamentals.md` + `MarketingHowTo.md` Section 6**
Profile = emotional response = promise. 3 adjectives from `Singer`. Value prop from `Pagan Marketing_Mindsets.md`. Picture quality from `Social Media Image Size Guide.md`.

## 3. Company Page Setup

Based on `10 Questions...md` (`domains/linkedin/`):
1. Define purpose: awareness / lead generation / hiring / partnerships?
2. Target audience: same avatar as `Customer Avatar Guide.md`; feed into `CRM/Marketing` spec.
3. Brand message: promise + 3 adjectives (`Singer Branding.md`).
4. Content plan: mix education + proof + offer (`Dubeau Content.md`); schedule per `SocialMediaHowTo.md` timing.
5. Metrics: followers, engagement rate, profile views, website clicks (`MarketingHowTo.md` Section 1b — measure ROI per activity; redirect if no ROI).

---
**Source Agreement**: `10 Questions` + `MarketingHowTo.md` + `SocialMediaHowTo.md` all agree: define audience and purpose first; measure; redirect if no ROI. Conflict: `10 Questions` = strategic/company-level; `SocialMediaHowTo.md` = tactical/post-level. Resolution: strategy (`10 Questions`) guides tactics (`SocialMediaHowTo.md`).
