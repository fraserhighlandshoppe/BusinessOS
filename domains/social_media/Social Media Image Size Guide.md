# Social Media Image Sizes

Tags: #marketing #socialmedia #reference

Dimensions in pixels (width x height). Note: platforms change specs over time - verify before major design work.

- **Facebook**: cover 828x315 | profile ≥180x180 | shared image 1200x900 | shared link preview 1200x628
- **Twitter**: header 1500x500 | profile 400x400 | timeline 506x253
- **Instagram / LinkedIn / Google+**: see infographic in raw wiki page (`hubspot-social-image-size-guide.jpg`)
- Pro tip: images on your own timeline may display differently than for others; low-quality images hurt engagement
